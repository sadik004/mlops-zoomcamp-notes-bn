# নোটবুককে পাইথন স্ক্রিপ্টে রূপান্তর (Turning the Notebook into a Python Script)

জুপিটার নোটবুক এক্সপেরিমেন্ট করার জন্য দারুণ হলেও একটি প্রোডাকশন পাইপলাইনের জন্য প্রয়োজন একটি নির্ভরযোগ্য ও স্থিতিশীল এন্ট্রি পয়েন্ট (Entry Point)। তাই এই পাঠে আমরা জুপিটার নোটবুকের কোডকে রিফ্যাক্টর করে একটি পরিষ্কার **`.py` পাইথন স্ক্রিপ্টে** রূপান্তর করব, যা সরাসরি টার্মিনাল, কোনো শিডিউলার বা অর্কেস্ট্রেটর থেকে চালানো যায়।

---

## ১. প্রয়োজনীয় কোড গুছিয়ে নেওয়া ও সেশন স্টেট দূর করা

নোটবুকের সেলগুলোকে তাদের কাজের ধরন অনুযায়ী ফাংশনে ভাগ করুন:
- ডেটা লোড করার জন্য একটি ফাংশন
- ফিচার প্রিপারেশনের জন্য একটি ফাংশন
- মডেল ট্রেনিং ও ইভ্যালুয়েশনের জন্য একটি ফাংশন

ফাংশন তৈরি করলে ভ্যারিয়েবলগুলো গ্লোবাল স্কোপে এলোমেলো হয়ে থাকে না এবং নোটবুকের সেল ভুল অর্ডারে রান হওয়ার ঝুঁকি দূর হয়।

![এক্সপেরিমেন্টের জন্য ব্যবহৃত মূল জুপিটার নোটবুক](images/02-notebook-to-script-01-notebook.jpg)

স্ক্রিপ্টের ভেতরেও MLflow ট্র্যাকিং কলগুলো স্বাভাবিকভাবেই কাজ করবে—যাতে প্রতিবার স্ক্রিপ্ট রান করলে একটি সম্পূর্ণ নতুন রান ডাটাবেজে তৈরি হয়।

## ২. কমান্ড-লাইন ইন্টারফেস (CLI) যুক্ত করা

মডেল ট্রেনিংয়ের জন্য কোন সালের কোন মাসের ডেটা ব্যবহার হবে, তা কখনো হার্ডকোড (Hardcode) করে কোডের ভেতর লিখে রাখা উচিত নয়। বরং `argparse` ব্যবহার করে ডাইনামিক আর্গুমেন্ট গ্রহণ করা উচিত:

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument('--year', type=int, required=True, help="ট্রেনিংয়ের সাল")
parser.add_argument('--month', type=int, required=True, help="ট্রেনিংয়ের মাস")
args = parser.parse_args()

# প্যারামিটার অনুযায়ী ফাংশন কল করা
run(year=args.year, month=args.month)
```

![পাইথন স্ক্রিপ্টে স্থানান্তর করা মডেল ট্রেনিং লজিক](images/02-notebook-to-script-02-script.jpg)

এখন কোডের কোনো লাইন পরিবর্তন না করেই যেকোনো নতুন মাসের ডেটা দিয়ে টার্মিনাল থেকেই ট্রেনিং শুরু করা সম্ভব:

```bash
python duration-prediction.py --year 2023 --month 3
```

## ৩. মেটাডাটা ও মডেল আর্টিফ্যাক্ট সংরক্ষণ

প্রতিটি রানে কোন মাসের ডেটা ব্যবহার হয়েছিল, ফিচার কী ছিল, এবং মডেল প্যারামিটার কী ছিল—তা MLflow-তে সেভ রাখুন। একই সাথে ট্রেইন্ড মডেল অবজেক্টটিও লগ করুন।

![প্যারামিটারাইজড স্ক্রিপ্ট রান এবং তার MLflow আউটপুট](images/02-notebook-to-script-04-run.jpg)

এই স্ক্রিপ্টটি এখন একটি স্বয়ংসম্পূর্ণ **পাইপলাইন এন্ট্রি পয়েন্ট**। যেকোনো অর্কেস্ট্রেটর (যেমন Prefect) সরাসরি এই স্ক্রিপ্টটিকে নির্দিষ্ট শিডিউলে কল করতে পারবে।
