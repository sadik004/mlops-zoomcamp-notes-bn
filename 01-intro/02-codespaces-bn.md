# গিটহাব কোডস্পেস (GitHub Codespaces)

GitHub Codespaces ক্লাউডে আমাদের জন্য সম্পূর্ণ রেডিমেড একটি ডেভেলপমেন্ট এনভায়রনমেন্ট (ভার্চুয়াল মেশিন) প্রদান করে। আপনার নিজের কম্পিউটারে আলাদা করে Linux, Docker বা কোর্সের অন্যান্য টুলস ম্যানুয়ালি ইনস্টল করার ঝামেলা এড়াতে এটি একটি চমৎকার বিকল্প।

---

## ১. ওয়ার্কস্পেস তৈরি করা (Create the workspace)

আপনার কোর্সের কাজের জন্য GitHub-এ একটি **পাবলিক রিপোজিটরি (Public Repository)** তৈরি করুন। রিপোজিটরিটি পাবলিক হওয়া জরুরি, কারণ পরবর্তীতে আপনার হোমওয়ার্ক সাবমিট করার সময় এর লিংক শেয়ার করতে হবে। রিপোজিটরি তৈরির সময় একটি `README.md` এবং পাইথনের জন্য `.gitignore` টেমপ্লেট যুক্ত করুন।

![GitHub Codespaces-এর ভেতরে VS Code এডিটরে খোলা একটি নতুন রিপোজিটরি](images/02-codespaces-01-editor.jpg)

রিপোজিটরির **Code** মেনুতে ক্লিক করুন, **Codespaces** ট্যাবটি বেছে নিন এবং `main` ব্রাঞ্চ থেকে একটি নতুন কোডস্পেস তৈরি করুন। গিটহাব ব্রাউজারের ভেতরেই Visual Studio Code ওপেন করে দেবে—যার ভেতরে টার্মিনাল, আপনার রিপোজিটরি এবং Docker আগে থেকেই কনফিগার করা থাকে।

---

## ২. প্রি-ইনস্টল করা টুলস যাচাই করা (Check the prepared tools)

কোডস্পেসের ভেতরের ইন্টিগ্রেটেড টার্মিনাল ওপেন করে Docker ঠিকঠাক কাজ করছে কি না তা টেস্ট করতে এই কমান্ডটি চালান:

```bash
docker run hello-world
```

![Docker রেডি অবস্থায় Codespaces টার্মিনাল](images/02-codespaces-02-terminal.jpg)

Codespaces ব্যবহার করলে বড় বড় ভার্চুয়াল মেশিন (VM) কনফিগার করার সময় বাঁচে। কোডস্পেসের ভেতরে আপনাকে নতুন করে Docker বা Docker Compose ইনস্টল করতে হবে না।

---

## ৩. পোর্ট ফরোয়ার্ডিং ও ডেস্কটপ এডিটর ব্যবহার (Use the desktop editor when you need forwarded ports)

সাধারণ কমান্ডের জন্য ব্রাউজার এডিটরই যথেষ্ট। কিন্তু জুপিটার নোটবুক (Jupyter Notebook) বা MLflow চালানোর জন্য নির্দিষ্ট পোর্ট (যেমন: 8888 বা 5000) আপনার কম্পিউটারের ব্রাউজারে দেখতে পোর্ট ফরোয়ার্ডিং দরকার হয়। আপনি যখন আপনার লোকাল কম্পিউটার থেকে জুপিটার বা MLflow সার্ভিসে কানেক্ট করতে চান, তখন কোডস্পেসটিকে আপনার লোকাল ডেস্কটপ Visual Studio Code-এ ওপেন করে নেওয়া সবচেয়ে সুবিধাজনক।

![ওয়ার্কস্পেসের ভেতরে চালু থাকা Jupyter Notebook](images/02-codespaces-03-jupyter.jpg)
