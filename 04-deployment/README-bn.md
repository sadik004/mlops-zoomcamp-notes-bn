# মডিউল ৪: মডেল ডিপ্লয়মেন্ট (Module 4: Model Deployment)

মডেল সফলভাবে তৈরি ও রেজিস্ট্রি করার পর সেটিকে বাস্তব ইউজার ও সিস্টেমের জন্য কীভাবে প্রোডাকশনে সার্ভ করতে হয়, তা এই মডিউলের মূল আলোচ্য বিষয়। অনলাইন ওয়েব সার্ভিস (Flask/Docker), মডেল রেজিস্ট্রি থেকে অটোমেটিক লোডিং, স্ট্রিমিং (AWS Kinesis/Lambda) এবং অফলাইন ব্যাচ স্কোরিং—এই সবগুলো আর্কিটেকচার এখানে আলোচনা করা হয়েছে।
